# Weather Card Project

A simple Python project using `uv` and the `rich` library.

### Project Files:
- `.python-version`: Keeps track of the Python version for this project.
- `.venv/`: The virtual environment created automatically by `uv`.
- `pyproject.toml`: Stores project settings and `rich` dependency.
- `uv.lock`: Locks exact package versions so everything works the same way everywhere.

### Virtual Environment (venv) Regen:
- When `.venv` is deleted, `uv run` automatically rebuilds it in a few milliseconds using `uv.lock`.
