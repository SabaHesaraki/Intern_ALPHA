# Terminal Toolkit

A tiny multi-tool command-line interface (CLI) application built as part of the Diapazon Academy assignment. It includes a unit converter, a tip calculator, and a text statistics tool.

## Features
1. **Unit Converter:** Convert between Celsius/Fahrenheit, Kilometers/Miles, and Kilograms/Pounds.
2. **Tip Calculator:** Calculate tips, total bills, and split costs among multiple people.
3. **Text Stats:** Count characters (with and without spaces) and total words in a given text.

## Requirements
- Python 3.10 or higher
- [uv](https://github.com/astral-sh/uv) (Fast Python package installer and runner)

## Installation & Usage

Clone the repository and run the application using `uv`:
```bash
# Run the application directly
uv run toolkit.py
